# Plantilla de caso

Esta plantilla define la estructura mínima de un caso de negocio para Proyecto_automatizaciones.

No contiene datos reales de ningún emprendedor.

Estructura:
- inputs/: datos iniciales del emprendedor.
- sources/: fuentes y documentos de investigación.
- dmv/: Documento Maestro Vivo del caso.
- output/: entregables generados por fases.
- reports/tmp/: reportes temporales no versionables.
- reports/official/: reportes oficiales de gates y auditorías aprobadas.

IMPORTANTE:
No guardar datos reales directamente en esta plantilla.
